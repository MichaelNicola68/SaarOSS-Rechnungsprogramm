# SaarOSS-Rechnungsprogramm

Deutschsprachiges, lokal arbeitendes Rechnungsprogramm für kleine Unternehmen unter Windows.

## Funktionen
- Kundenverwaltung
- Angebote und Rechnungen mit PDF-Ausgabe
- konfigurierbare Nummernkreise
- Zahlungsverwaltung
- Logo und Briefkopf
- Datensicherung und Wiederherstellung
- geprüftes ZIP-Updatesystem
- MSI-Installation unter Windows

## Installation
Im Bereich **Releases** `SaarOSS-Rechnungsprogramm-1.0.0-win-x64.msi` herunterladen, SHA-256 prüfen und installieren. Das Release ist self-contained.
